# splats

A free collection of 109 objects as 3D Gaussian splats, scanned from video,
converted from meshes, and generated by an AI model.

## Install

```bash
pip install splatset
```

```python
import splatset

s = splatset.load("plant")   # downloads once, caches, decodes
s.positions                  # (113648, 3) float32 xyz
s.colors                     # (113648, 4) uint8 RGBA
```

You never write a URL. Ask for what you want and it is fetched:

```python
splatset.find(source_method="capture")   # real scans only
splatset.find(open_license=True)         # freely licensed only
splatset.load("lucy", lod="10k")         # mesh objects come in 10k/100k/500k/1M
splatset.load_random()                   # or just give me one
splatset.download("./splats")            # local copies
```

There is a command line too:

```bash
python -m splatset list --source mesh2splat --lod 10k
python -m splatset get lucy --lod 1m
```

Full package docs: [python/README.md](python/README.md).

See the [project page](https://marcelpadilla.github.io/Projects/Gaussian_Splat_Object_Dataset/)
for the collection, the licenses and the file format.
